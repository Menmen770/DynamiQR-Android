# דוח פערים: React Native vs. Native Android (Java)

מיפוי מלא של כל הרכיבים, המסכים והלוגיקה שקיימים בפרויקט ה-React Native וטרם הוטמעו בגרסת ה-Android Native המקצועית.

| מסך | תיאור | סטטוס |

## 2. רכיבי UI ופיצ'רים מתקדמים (UI/UX Gaps)

### א. מערכת האימות (Auth)
- [ ] **Google OAuth:** לוגיקה אמיתית של התחברות עם Google (Firebase או Google Identity).
- [ ] **Validation:** הודעות שגיאה בזמן אמת מתחת לשדות (ולא רק בבאנר עליון).
- [ ] **Password Toggle:** עין להצגת/הסתרת סיסמה בעיצוב המדויק.

### ב. דאשבורד (Dashboard)
- [ ] **Stats Modal:** חלונית המציגה סטטיסטיקות סריקה עבור קודים דינמיים.
- [ ] **Edit Modal:** עריכה מהירה של יעד קוד דינמי בלי להיכנס למחולל.
- [ ] **Empty States:** עיצוב "אין קודים" עם איורים וכפתורי הנעה לפעולה.
- [ ] **Pull to Refresh:** רענון הרשימה במשיכה מלמעלה.

### ג. מחולל הקודים (Generator)
- [ ] **Gradient Picker:** בחירת צבעי התחלה וסיום וזווית (Angle) לגרדיאנט של ה-QR.
- [ ] **Custom Logo Upload:** העלאת לוגו מהגלריה (Image Picker) ועיבוד שלו (Resize/Compress).
- [ ] **QR Placement in Stickers:** מיקום מדויק של ה-QR בתוך ה"חור" של הסטיקר (18 וריאציות).
- [ ] **Export Engine:** שמירת ה-QR כקובץ תמונה (PNG/SVG) לגלריה או שיתוף.

---

## 3. תוכן וטקסטים (i18n & Assets)

- [ ] **תמיכה ב-RTL מלא:** וודא שכל האפליקציה מתנהגת נכון בעברית (יישור לימין).
- [ ] **Marketing Content:** כרטיסיות פרסום (Promotional cards) בדאשבורד ובדף הלמידה.
- [ ] **Assets:** המרה של כל אייקוני Tabler (מעל 30 אייקונים שונים בשימוש ב-RN) ל-Vector XML.

---

## 4. ארכיטקטורה וקוד (Clean Code)

- [ ] **Dependency Injection:** שימוש ב-Singleton עבור `RetrofitClient` ו-`AuthManager`.
- [ ] **Repository Pattern:** הפרדה בין הקריאה ל-API לבין הלוגיקה ב-Fragment.
- [ ] **Base Classes:** שימוש ב-`BaseActivity` ו-`BaseFragment` למניעת כפילות קוד (בוצע חלקית).
